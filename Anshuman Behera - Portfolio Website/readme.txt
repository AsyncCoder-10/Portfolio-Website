# Anshuman Behera - Portfolio Website

This is my personal portfolio website showcasing my skills, projects, and professional experience as a Frontend Developer, Vlogger, and Photographer.

## 🚀 Features
- Clean and modern design
- Responsive layout for all devices
- Professionally structured sections: Home, About, Skills, Projects, Blog, Contact
- Tech Stack Icons with hover tooltips
- Integrated links to social platforms (LinkedIn, GitHub, YouTube, Instagram)
- Dynamic text animations and smooth scrolling
- Downloadable CV option
- AI-powered features in select projects (e.g., PDF to questions)

## 🛠️ Technologies Used
- HTML5, CSS3, JavaScript
- Angular & React
- Bootstrap & Tailwind (if used)
- Font Awesome & Devicon for icons
- Google Cloud, Firebase, AWS, OpenAI API (in projects)
- FastAPI, Python (for backend/AI integration)

## 📂 Folder Structure
- /assets - Images, icons, and other media
- /css - Stylesheets
- /js - Scripts and logic
- /components - Reusable UI components
- index.html - Main landing page

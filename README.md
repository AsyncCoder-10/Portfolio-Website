# Emerald Canvas

Prompt:

Design and build a modern, minimalist portfolio website with a green and black color theme. Requirements:

Visual Style

Primary background: deep black (#0A0A0A or #0D0D0D)

Accent color: vibrant green (e.g., #00FF7F, #39FF14, or a more muted emerald #10B981 — pick one and use it consistently)

Secondary text: light gray/off-white (#E5E5E5) for readability

Use subtle gradients, glowing green accents on hover states, and soft shadows for depth

Modern sans-serif font pairing (e.g., Inter or Space Grotesk for headings, system font for body)

Generous whitespace, clean grid layout, smooth micro-interactions/animations on scroll

Sections

Hero — Name, title/tagline, short intro, animated green accent (e.g., glowing gradient blob or particle effect), CTA buttons (Resume/Contact)

About — Short bio, profile photo, skills/tech stack as icon grid or tags

Projects — Card-based grid with hover effects (image, title, tech stack tags, live link + GitHub link), 3-6 featured projects

Experience/Timeline — Vertical timeline with green connecting line, company, role, dates, key achievements

Skills — Categorized (e.g., Frontend, Backend, Tools) with progress bars or tag clouds

Contact — Simple form + social links (GitHub, LinkedIn, email), green-accented submit button

Technical

Responsive (mobile-first)

Smooth scroll navigation with active-section highlighting

Dark mode is default (this IS the theme)

Subtle scroll-triggered animations (fade/slide-in)

Fast-loading, accessible (proper contrast ratios despite dark theme)

Tech stack: React + TypeScript + Tailwind CSS, with Framer Motion for animations
